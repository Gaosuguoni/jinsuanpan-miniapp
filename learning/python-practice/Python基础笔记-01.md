## 1. 变量：贴了标签的盒子

```python
a = 5          # 把 5 放进叫 a 的盒子
name = "苹果"   # 把文字放进叫 name 的盒子
```

- `=` 是**赋值**（把右边的值放进左边的盒子），不是数学里的"等于"
- 命名规则：字母/数字/下划线，**不能以数字开头**，区分大小写（`Age` 和 `age` 是两个盒子）
- 项目里：一笔账的每个字段都是一个变量（品名、数量、单价）

---

## 2. 类型：盒子里装的是什么

| 类型 | 名字 | 例子 |
|---|---|---|
| `int` | 整数 | `5`、`50`、`160` |
| `float` | 小数 | `3.2`、`0.5` |
| `str` | 字符串（文字） | `"苹果"`、`"50斤"` |
| `bool` | 真/假 | `True`、`False` |

```python
type(5)      # <class 'int'>
type(3.2)    # <class 'float'>
type("苹果")  # <class 'str'>
```

**项目里**：语音识别出来的是 `str`（文字），要算钱必须先转成 `int` / `float`。

---

## 3. 文字 vs 数字（最重要的一个知识点）

> **引号决定它是"文字"还是"数字"。**

```python
"5" + "5"    # '55'    ← 文字相加 = 拼接
5 + 5        # 10      ← 数字相加 = 算数
"苹果" * 3    # '苹果苹果苹果'  ← 文字 × 数字 = 重复
"5" + 5      # ❌ TypeError  ← 文字和数字不能直接相加
```

**为什么重要**：这是初学者 80% 报错的来源。看到 `TypeError` 先想"是不是把文字当数字用了"。

---

## 4. 类型转换：把一种类型变成另一种

| 写法 | 结果 | 说明 |
|---|---|---|
| `int("50")` | `50` | 文字 → 整数 |
| `int("3.2")` | ❌ ValueError | int 只认整数 |
| `float("3.2")` | `3.2` | 文字 → 小数 |
| `str(50)` | `"50"` | 数字 → 文字 |

**项目里**：`"20斤"` 里的 `"20"` 必须 `int()` 之后才能乘单价。

---

## 5. 字符串：按位置取字符

字符串是**一排排好队的字符**，编号**从 0 开始**：

| `s = "50斤"` | `5` | `0` | `斤` |
|---|---|---|---|
| 正数编号 | `s[0]` | `s[1]` | `s[2]` |
| 负数编号 | `s[-3]` | `s[-2]` | `s[-1]` |

```python
s[0]      # '5'         第一个
s[-1]     # '斤'        最后一个（负数从右边数）
s[:2]     # '50'        从开头到第 2 位之前
s[2:]     # '斤'        从第 2 位到最后
s[:-1]    # '50'        从开头到最后一个之前
len(s)    # 3           长度（有几个字符）
```

**项目里**：把 `"50斤"` 拆成数量 `50` 和单位 `"斤"`，用的就是 `s[:-1]` 和 `s[-1]`。

## 6. 列表：一排编号的盒子

```python
bills = ["苹果", "白菜", "土豆"]
bills[0]            # '苹果'（编号同样从 0 开始）
bills[-1]           # '土豆'（最后一个）
bills.append("茄子") # 往末尾加一个
len(bills)          # 4
```

**项目里**：一天的流水就是一个列表，里面装着很多笔账。

## 7. 字典：带名字标签的盒子

```python
bill = {"name": "苹果", "total": 160}
bill["name"]        # '苹果'  ← 用名字取，不用记编号
bill["total"]       # 160
bill["qty"] = 50    # 新增一个字段
```

**项目里**：一笔账就是一个字典（类型、品名、数量、单价、总额）。

## 8. 条件：岔路口

```python
if "块" in s:
    print("是块的说法")
elif "元" in s:
    print("是元的说法")
else:
    print("没听懂")
```

- `if` = 如果…；`elif` = 否则如果…；`else` = 否则…
- `in` = "包含"（`"块" in s` 判断 s 里有没有"块"这个字）
- `==` 判断是否相等（**一个 `=` 是赋值，两个 `==` 才是比较**）
- **缩进（4 个空格）决定哪些代码属于这个 if**

**项目里**：判断一句话是"进货 / 卖货 / 赊账 / 收款 / 支出 / 损耗"的哪一种。

## 9. 循环：重复做同一件事

```python
bills = [{"name": "苹果", "total": 160}, {"name": "白菜", "total": 60}]

total_sum = 0
for b in bills:            # 每一圈，b 就是其中一笔账
    print(b["name"], b["total"], "元")
    total_sum += b["total"]   # 等价于 total_sum = total_sum + b["total"]

print("合计", total_sum, "元")
```

**项目里**：一天几十笔账，靠循环逐笔统计出"今日汇总"。

## 10. 函数：一台可复用的机器

```python
def money(x):          # def = 造一台机器，机器名叫 money，要放进一个原料 x
    return f"{x:.2f}"  # return = 把加工好的结果送出来

print(money(3.2))      # 3.20
```

- `def` 定义函数（造机器）；`()` 调用函数（使用机器）
- **`return` 和 `print` 的区别**：
  - `print` 只是显示给你看，程序拿不到这个值
  - `return` 是把结果交给程序继续用（可以再计算）
  - 例子：`money(3.2) + "元"` 能用，因为 return 出了文字；如果里面是 print，就不能再用了

**项目里**：`kuai_to_num()`、`split_qty()`、`summarize()` 都是函数。

## 11. 常用小工具

| 写法 | 作用 | 例子 |
|---|---|---|
| `f"{x}"` | 把变量塞进字符串 | `f"共 {n} 笔"` |
| `f"{x:.2f}"` | 保留两位小数 | `f"{3.2:.2f}"` → `'3.20'` |
| `round(x, 2)` | 四舍五入到两位 | `round(3.256, 2)` → `3.26` |
| `print(a, b)` | 打印多个值（逗号隔开，逗号后加空格） | `print("苹果", 160)` |
| `len(x)` | 长度 | `len("50斤")` → 3 |
| `type(x)` | 查类型 | `type(5)` → `int` |

## 12. 新手最容易踩的 6 个坑

| 坑 | 表现 | 怎么避免 |
|---|---|---|
| **全角符号** | `SyntaxError: invalid character '：'` | 写代码用**英文输入法**；`：`→`:`、`（`→`(`、`，`→`,` |
| **中文引号** | `"苹果"` 或 `'苹果'` 报错 | 用英文 `"` 或 `'` |
| **缩进不对** | `IndentationError` | `if` / `for` / `def` 里面的代码**统一 4 个空格** |
| **文字当数字用** | `TypeError`、`'55'` 这种奇怪结果 | 先 `int()` / `float()` 转换 |
| **一个 `=` 当比较** | 条件判断永远成立/报错 | 比较用 `==`，赋值才用 `=` |
| **变量名拼错** | `NameError` | 大小写、下划线要和定义时**一字不差** |

## 13. 自测题（遮住答案，先自己答）

1. `type(3.0)` 显示什么？
2. `"5" + "5"` 和 `5 + 5` 分别是什么？
3. 想用文字 `"12"` 做加法，怎么写？

5. `4`
6. 列表按**位置编号**取（`bills[0]`）；字典按**名字**取（`bill["name"]`）
7. `total_sum = total_sum + b["total"]`
8. `return` 把结果交给程序继续用；`print` 只是显示出来
9. `if "块" in s:`
10. 中文输入法会打出全角符号（`：（）"，`），Python 只认半角，直接报语法错误
