# Python 基础练习（FDE 学习计划 W1）

这是我自学 Python 的第一批练习，全部围绕「金算盘」记账项目的真实场景设计：

| 文件 | 练习 | 涉及知识 |
|---|---|---|
| ex01.py | 用变量存一笔账，计算总额 | 变量、类型、算术、f-string |
| ex02.py | 金额格式化函数 money() | 函数、`:.2f` |
| ex03.py | 把"3块2""3块2毛5"转成数字 | 字符串拆分、条件判断、浮点舍入 |
| ex04.py | 把"50斤"拆成数量和单位 | 字符串索引、类型转换、元组返回 |
| ex05.py | 列表存 5 笔账并循环汇总 | 列表、字典、循环、累加 |

学习方式：先自己写 → 跑通 → 与期望输出对照 → 卡住 15 分钟再看参考。
